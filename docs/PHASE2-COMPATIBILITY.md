# 二期兼容规则

更新：2026-11-03。当前开发源码 / 开发包为 0.3.0-dev.2，帧协议 1，存档 ZIP 格式 1。旧 dev.1 的验证记录按原日期保留；当前软件验证见[修复记录](FIELD-FIXES-2026-11-03.md)，不据此新增游戏内兼容承诺。

当前 `CompatibilityCatalog.Released` 没有开放的迁移组合。下面是实现与样本范围，不能当作游戏内支持清单。

当前发现登记只核实了吸血鬼幸存者 `010089A0197E4000` 与死亡细胞 `0100646009FBE000` 的 Switch 游戏标识（2026-11-02，只读游戏清单）。哈迪斯、哈迪斯 2、空洞骑士和丝之歌的 Switch 标识仍待核对；可使用已实现的电脑存档发现与独立备份，不据同名游戏或候选适配器开放 Switch 配对。**游戏标识核实、文件可发现和备份成功均不等于允许迁移。**

- **吸血鬼幸存者 / 1794680**：有效 PC 文件发现、精确字节摘要检查及备份。已只读核对一份本机 PC 文件；Switch 封装与进度字段转换仍需样本。
- **死亡细胞 / 588650**：格式 1、SHA-1、分块与永久进度候选转换；当前一局重置，目标版本和 DLC 标记保留。PC 文件只读检查与合成数据转换通过；双端组合待准入。
- **哈迪斯 / 1145360**：Windows 共用目录按用户和 Profile 槽位发现与备份。已只读读取本机 Profile；尚不做未识别格式的直接复制。
- **哈迪斯 2 / 1145350**：独立目录和候选入口；没有沿用一代格式假设。双端 Profile 待登记。
- **空洞骑士 / 367520**：固定字符串封装、AES / JSON 候选转换、目标其他数据保留；合成数据双向转换及协议保护流程通过。真实槽位与版本组合待准入。
- **丝之歌 / 1030300**：独立标识和路径，共享封装基础实现；需要独立版本与槽位记录。

每条可发布规则至少记录 Steam BuildID、分支、两端格式版本、Switch 应用 ID / 内容版本、影响存档的 DLC、方向、完整度与证据。保存文件内的 Version 字段不能替代安装版本。仅格式可解析、同名游戏、时间较新或文件名相似都不启用迁移。

原生 HOME 精选暂不开放。只有当前环境完成 HOME / 全部软件 / 分组、十轮隐藏恢复、三次重启、入口保护、离线恢复和内容不变核对后，才允许进入启用阶段。

管理更新需要配套程序明确提供 `install.plan.v1`、`package.dependencies.v1` 和 `operations.status`。旧版仍可使用原有查询／文件／备份等接口；新管理安装不会把旧服务忽略字段当作支持。

电脑夹具、目标 NRO 构建、真实设备和游戏内检查分开记录；后两者的结果不能由前两者推断。
