SwitchDesk 开发进度报告

核对日期：2026 年 10 月 29 日（北京时间）
本地开发版本：0.3.0-dev.1 · 分支：phase2-foundation · 源码标识：39c6a308a1aa

1. 现在开发到了什么程度

已经从方案调研进入可运行的开发预览阶段：Windows 图形界面、Switch 配套程序、基础管理功能和二期主要软件流程都已写出；距离“主要功能在真实 Switch 上完整验收、可以放心日常使用”还有明显差距。

  • 基础功能：USB 识别、主机资料、游戏列表和容量查看已获得一次真实设备只读证据。备份、恢复、文件传输、安装、导出等已有代码和电脑测试，尚未完成真机写入闭环。
  • 二期存档互通：比较、冲突判断、保护副本与写入基础已实现，部分游戏已有候选转换；目前开放的跨平台迁移组合为 0。
  • 二期精选游戏：方案和恢复模型已实现；原生 HOME 隐藏接口与恢复验收未完成，功能关闭。
  • 二期更新 / DLC：自有来源、下载校验、预检、安装排序及结果复核的软件流程已实现；真实内容安装、真实 NAS 和外部服务器仍待验证。
  • 交付状态：已有本地 0.3 开发包、配套 NRO 和对应源码；项目记录中的公开预览版仍是 Windows 0.2.5 / Switch 0.2.4，未完成 0.3 公开发布。

本报告不按任务勾选数量计算整体完成百分比：格式转换、断电恢复和游戏内续玩等关键门槛，不能用界面或测试数量抵消。本文为日期快照；持续进度仍以 PROGRESS、二期任务和兼容规则为准。

2. 最初想做的功能，分别实现了吗

2.1 插线识别 Switch，查看系统和大气层版本

实现状态：已实现，有有限真机只读验证。

已有 USB 连接与诊断、设备识别、型号、系统固件、大气层和系统环境显示；emuMMC 有明确标记，断线后保留带同步时间的离线记录。

已有设备证据来自 2026-10-23 的旧配套 0.2.4。连接条件包括支持数据传输的 USB 线、正确的 WinUSB 驱动，以及在 Switch 上启动配套程序；不是只插线就能管理任意原厂系统。连续拔插、休眠恢复、其他型号和固件尚未验收。

2.2 查看主机游戏列表、大小、更新与 DLC

实现状态：已实现，有有限真机只读验证。

已有游戏封面与列表、大小、组件信息、本体 / 更新 / DLC 展开；电脑文件与主机内容合并展示，支持搜索、来源筛选和网格 / 列表切换。

一次真实读取获得 31 条游戏记录，其中 1 条内容信息不可读取，原因仍未查明。这个结果不能直接解释成游戏损坏。跨存储组件、归档内容和卡带等情况还需补充检查。

2.3 查看 SD 卡与内部存储剩余空间

实现状态：已实现，有有限真机只读验证。

可以查看 SD 卡与当前系统用户分区的总量和剩余容量。emuMMC 环境下显示的是当前环境信息，不能自动当作另一套 sysMMC 环境的容量结果。

2.4 存档备份，并拖到电脑保存

实现状态：备份、拖出、历史与恢复流程已实现；完整真机验收未完成。

已有按游戏 / Switch 用户读取存档、生成带文件清单和校验信息的 ZIP、备份历史、连接后自动备份、相同内容去重、保留策略，以及恢复前保护副本和恢复入口。拖到资源管理器的代码与隔离测试已有。

真实设备目前只证明读取过存档清单，没有证明实际备份、拖出、恢复及 A→B→A 往返全部成功。真实 Explorer 拖放、多用户备份、掉线和保护副本恢复仍待验收。旧版恢复也没有掉电自动回滚保证。

2.5 不拔 SD 卡，向 Switch 安装游戏

实现状态：安装路径和队列已实现；真实安装闭环未验收。

已有 USB 流式安装入口，选择或拖入 NSP / XCI / NSZ / XCZ，解析组件、集中预检空间、进入队列，并处理停止、跳过和失败状态。本地更新包可走这条路径。

这些格式进入解析与安装代码，不等于每种真实包都已成功安装。压缩格式预检有未压缩 .cnmt.nca 等条件。还缺真实样本安装、版本变化、启动、存档延续、大文件和中断验证。

2.6 把主机游戏本体保存到电脑

实现状态：按组件导出功能已实现；真实导出与重新安装闭环未验收。

可以选择本体、更新和 DLC 组件，走导出 NSP 与电脑库登记的流程。仍需实际导出、校验、重新安装并启动，才能确认完整可用。

3. 已扩展实现的软件功能

以下描述代码和电脑验证范围，除第 2 节标明的只读项目外，不新增真机通过结论。

  • SD 文件管理：目录浏览、文件和目录双向传输、新建目录、重命名、删除、受保护路径检查及中断清理。真实 FAT32、超过 4 GiB、冲突和断线仍待验证。
  • 电脑游戏库：目录扫描、本地索引、摘要校验、导出清单读取、待识别状态。已移动或删除的文件记录尚不能自动清理。
  • 界面与操作：澄空主题、浅色 / 深色 / 跟随系统、游戏详情、离线资料、连接诊断和任务结果。真实键盘焦点、显示器 DPI 切换与可访问性仍需人工检查。
  • 画面预览入口：可启动独立官方 SysDVR 客户端并提供配置引导；不是内置完成的串流系统，尚缺持续 30 分钟音画等验收。
  • 新版保护流程：能力协商、操作 ID、持久日志、断线后只读核对。旧配套不声明新能力时，新写入入口会禁用。

4. Steam 与 Switch 存档互通

已实现的公共基础

  • 按有效路径、账号和槽位发现 PC 存档，并与 Switch 存档配对。
  • 区分游戏保存时间、观察时间和迁移时间，以内容指纹判断单边变化、双方冲突和内容未变；不按“较新时间”自动覆盖。
  • 迁移前保存双方原始副本，生成完整目标快照；保留未选槽位、目标其他数据与设备 / 用户身份检查。
  • PC 单槽原子替换；新版 Switch 端暂存、完整校验、空间预检、SD 保护副本、一次提交和提交后读回的代码已实现。
  • 操作状态可持久保存；异常或重连后先核对，不自动重试写入。普通历史去重，Recovery 保护副本独立保留。
  • PC 写入要求退出 Steam；观察到可疑云替换时保留副本并提示比较，不修改 Steam 云设置。
  • 游戏详情中的跨平台比较面板、固定操作区、迁移范围提示和未准入禁用逻辑已实现。

六款游戏的实际状态

  1. 吸血鬼幸存者：有效 PC 存档发现、只读检查、精确字节摘要和备份基础已有；Switch 封装、旧引擎 / Unity 差异、字段归属及双向转换未完成。文件中的 Version 不能代替游戏安装版本。
  2. 死亡细胞：格式 1 解析、摘要校验、限额分块解压与永久进度候选转换已有，PC 样本只读检查和合成数据测试通过。候选转换会重置当前一局，保留目标版本与 DLC 标记；未获得游戏内兼容结论。
  3. 哈迪斯 1：PC 用户与 Profile 槽位发现、只读检查和备份入口已有；Profile 格式、进度 / 配置归属和转换未完成。
  4. 哈迪斯 2：独立标识、目录与候选入口已注册；双端 Profile、格式和转换准入未完成，不能沿用一代结论。
  5. 空洞骑士：有边界的字符串封装、AES / JSON 候选转换及合成数据双向测试已有；真实版本、槽位与游戏内续玩未准入。
  6. 丝之歌：独立标识和路径、共享封装转换基础已有；真实版本和槽位必须独立验证，不能直接继承空洞骑士的支持规则。

结论：六款均未开放跨平台迁移。 源码 CompatibilityCatalog.Released 当前为空，应用需要查到符合版本、分支、DLC 和证据条件的规则才能写入。注册六个适配器不等于支持六款迁移。

5. 原生 HOME 精选 / 隐藏游戏

目前：模型已有，原生能力未完成准入，操作关闭。

已实现精选方案、设备 / 环境绑定、入口保护、PC 与 SD 日志契约、撤销和部分失败回退模型；电脑模拟后端测试通过。

尚未完成原生逐应用隐藏 / 显示接口及全量枚举、脱离电脑的主机恢复入口、日志异常路径，以及 HOME / 全部软件 / 分组的实际效果核对。还需至少 10 轮隐藏 / 恢复与 3 次重启，并覆盖休眠、新安装、更新后状态保持及内容未改动检查。

因此，目前不能使用它隐藏原生 HOME 游戏图标，也不能把电脑端筛选当作这项功能完成。

6. 游戏更新与 DLC 管理

已实现的软件流程

  • 目录与内容分开：TitleDB 提供元数据；自己的本地目录、已连接 NAS / UNC、HTTP / HTTPS 索引提供安装包。
  • 更新比较：按组件数字版本区分游戏更新、新 DLC 与 DLC 更新；保留来源和获取时间，目录未知不会当作没有更新。
  • 来源配置与索引：索引格式 1、从主机解析真实包生成索引、HTTPS 凭据的 Windows 安全存储引用。
  • 下载与校验：最多两个并行下载；强 ETag 条件续传、资源变化重来、超时 / 取消、长度与 SHA-256 校验，以及来源范围与重定向限制。
  • 安装前检查：复核真实包身份、组件归属、系统与游戏版本依赖、空间和降级；无法精确筛选的混合包拒绝安装。
  • 集中执行：一次确认后先保护相关所有用户存档，再按更新 → DLC → DLC 更新串行安装；之后复读数字版本，区分升级、同版无变化和失败。
  • 异常核对：保留部分完成结果，重连先读取操作状态和实际版本，不直接重复安装。

仍没有完成的部分

  • 实际 NSP / XCI / NSZ / XCZ 内容的更新与 DLC 安装、启动及存档延续闭环。
  • 真实 NAS、外部服务器、超过 4 GiB、资源变化、空间不足、拔线和程序退出验证。
  • 更新后保持原隐藏状态；这一项依赖第 5 节原生隐藏准入。
  • 公共 TitleDB 的最近实际请求在此前验证中失败；缓存及解析分支有电脑测试，不能声称当前公共目录联网可用。本次没有重新访问该服务。

现有本地来源及本机回环 HTTP 的合成下载已经通过。它不是公网游戏包搜索器，也不提供 DLC 授权解锁。新版管理流程还要求配套声明 install.plan.v1、package.dependencies.v1、operations.status；不能用电脑端升级代替主机配套升级。
