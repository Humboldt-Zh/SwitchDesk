# 已知问题与当前边界

适用：Windows 0.2.5 / Switch 0.2.4，2026-10-23。以下记录当前实现的行为、边界与注意事项。

1. **存档写回无法保证掉电原子回滚。** 写回中断可能留下部分内容；Recovery 是恢复来源，不是主机自动回滚。先用专门测试存档完成 A→B→A 与中断恢复验证。
2. **安装与旧内容占用。** 游戏更新包通过安装路径处理，没有自动更新下载功能。 此分支保留旧注册内容以降低升级中断影响，可能留下旧 NCA 占用；中断恢复与清理步骤需要结合任务日志处理，本版不提供自动内容回收或卸载。
3. **大文件与连接边界。** 大文件、物理拔插、休眠和双端进程退出的检查步骤见路线与连接诊断。普通 SD 文件复制受 FAT32 限制；流式安装走内容接口。
4. **设备身份存在降级路径。** 硬件查询失败时使用 SD 文件中的随机身份；整卡复制可能复制该身份，跨主机恢复隔离还需加强与验证。
5. **SysDVR 配置。** 串流入口启动独立的 6.3 客户端，传入 `usb` / `--title`；请结合上游客户端版本和说明配置。
6. **电脑库缺失文件记录。** 当前扫描新增／更新项目，不自动清除已移动或删除的路径；需要缺失状态与用户可控清理。
7. **历史校验开销。** 保留策略可能重复读取多个大快照；大规模实际备份性能尚未测量。
8. **快照处理预算。** 已有限制清单大小与条目数，但缺少独立的总解压字节和耗时预算；不要导入来源不明的快照。
9. **无应用内更新事务。** NRO 需要退出后手动替换；当前没有签名更新包、自动回退或自身覆盖入口。
10. **交互与兼容范围。** Applet、Explorer 拖放、DPI 切换和不同型号的检查项目见验证记录与后续路线。
11. **部分游戏记录不可读取。** 一次真机读取存在一条这样的记录；归档、卡带和内容记录原因仍待分析，不自动删除或重装。

主机任务断线后结束，重连可重试；不承诺断点续传。写回开始后普通取消被禁用，仍无法防止物理断线和掉电。首次建议仅做只读浏览，写入验证使用独立测试内容和外部备份。
