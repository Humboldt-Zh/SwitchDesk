# 0.3.0-dev.1 开发验证

整理日期：2026-10-24。源标识 `39c6a308a1aa`；完整来源摘要 `39c6a308a1aabbebaf1091356a113a22703a618c1780223799bc432ee39ddd6c`。Windows 和 NRO 内的来源标识已核对一致。

## 电脑自动化

- .NET SDK 10.0.402，Windows x64；构建零警告、零错误。
- **117 项自动化测试通过**，包含原有 70 项。新增覆盖指纹冲突、保存时间与迁移时间、SQLite 修订号、槽位保护、转换封装、恢复保护、包身份与依赖、同版无变化、批量顺序、HTTP 来源边界、ETag 变化、取消／停滞、双下载上限及断线只读核对。
- 实际 WPF 命令通过隔离协议夹具检查备份、批量安装停止／跳过、旧配套能力禁用、离线与重连、跨平台比较；没有连接 Switch。
- 一份合成安装包经真实本机回环 HTTP 下载并通过 SHA-256；目录和文件均为测试生成数据，没有使用实际游戏安装包。
- Windows 凭据管理器已进行一个随机临时通用凭据的写入、读回和删除检查，通过。未读取用户已有凭据，没有记录测试密码。
- 三款 PC 存档进行只读检查，最终内容摘要与检查开始时一致。实际路径、账号、摘要和报告保留在私有目录，不随项目发布。

## 界面

- 500 项游戏夹具，浅／深主题，1050 / 1280 / 1920 DIP，96 / 192 DPI 渲染比例。
- 跨平台面板额外覆盖 1050 × 640 DIP 最小窗口高度；操作区固定，正文滚动，未准入操作禁用。
- 手工查看 WPF 渲染后修正下拉框显示内部类型／对象的问题，并增加渲染检查；状态原因保留在固定操作区，深色下拉箭头可见。
- 更新清单额外渲染检查勾选框、数字版本及旧配套禁用状态。界面图明确为测试资料，不放入当前 README 的真实游戏截图位置。
- 渲染比例检查不是实际显示器 DPI 切换，键盘焦点、Explorer 及真实显示环境继续保留人工检查项。

## 原生代码与目标

- devkitA64 GCC 16.1.0，固定 libnx / newlib 与 Sphaira 基线，Switch NRO 目标构建通过。
- 便携 C++ 协议、路径、恢复空间预算、操作 ID、64 位 argv 以及替代绘图管理页使用 ASan / UBSan 检查，通过。
- sanitizer 在电脑 Linux 测试环境运行，不覆盖 Horizon 服务、主机 HOME、实际存档日志或安装引擎的设备行为。
- 本轮没有部署 NRO、没有向主机发出存档写回、安装、隐藏或删除请求。原有 0.2.4 的设备记录继续独立保留。

## 网络与兼容边界

本机实际访问公共 TitleDB 的原始接口和固定 API 备用接口未成功，已记录为来源暂不可用；没有将失败请求的时间写成目录获取时间。固定接口解析／切换、缓存原时间和自有索引继续使用的分支由电脑夹具覆盖。自有本地与回环 HTTP 来源通过，实际 NAS／公网服务器仍需对应环境记录。

迁移准入表为空；原生隐藏关闭。Hades 两代目前没有开放格式转换，吸血鬼字段转换仍待双端样本。完整度、版本、DLC 与往返检查继续按[逐项任务](PHASE2-TASKS.md)登记。
